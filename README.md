# LifeOS — AI-Powered Personal Life Manager

**LifeOS** is a comprehensive, privacy-first personal life management application that acts as your centralized AI-powered executive assistant. Built with a FastAPI backend and a React/Tailwind frontend, LifeOS streamlines your day-to-day productivity, finances, health habits, schedules, documents, and shopping.

---

## 🌟 Key Features

- **📊 Intelligent Dashboard**: Overview of your day, active KPIs, daily plan generated by AI, and priority actions.
- **🤖 AI Life Assistant**: Streaming AI conversation (powered by Claude / LLMs) to plan your day, analyze expenses, summarize documents, and manage tasks.
- **✅ Task & Project Management**: Organize tasks by priority, tags, status, and deadlines.
- **💳 Expense & Budget Tracking**: Monitor categorized expenditures against monthly caps with threshold warnings (80% / 100%).
- **📄 Smart Document Locker & OCR**: Store critical personal documents (IDs, policies, warranties) with automated OCR to parse and extract expiry dates.
- **📅 Calendar & Appointments**: Integrated scheduling with 24-hour proactive alerts.
- **🎯 Habits & Daily Routines**: Streak tracking, consistency heatmaps, and reminders.
- **🛒 Shopping Lists**: Dynamic checklist and items organization.
- **🔔 Proactive Notifications & Reminders**: Smart alerts for overdue tasks, nearing budgets, expiring documents, and upcoming appointments.
- **🔒 Authentication & Security**: JWT-based authentication with secure cookie handling, password hashing, and user-isolated data tenancy.

---

## 🏗️ Tech Stack

### Frontend
- **Framework**: React (SPA) with JavaScript / JSX
- **Styling**: Tailwind CSS & Lucide Icons
- **HTTP Client**: Axios
- **Build Tool**: Webpack / CRA / Craco

### Backend
- **Framework**: FastAPI (Python 3.10+)
- **Database**: MongoDB (via Motor async driver)
- **Authentication**: JWT (JSON Web Tokens) + Passlib (bcrypt)
- **AI / OCR Integration**: Emergent LLM Integrations (Claude Sonnet 4.6)
- **Testing**: Pytest

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18+) and **Yarn** or **npm**
- **Python** (v3.10+)
- **MongoDB** (running locally on port 27017 or a MongoDB Atlas URI)

---

### Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Create and activate a Python virtual environment:
   ```bash
   python -m venv venv
   # On Windows:
   .\venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Configure environment variables:
   - Copy `.env.example` to `.env`:
     ```bash
     cp .env.example .env
     ```
   - Fill in your configuration:
     ```env
     MONGO_URL="mongodb://localhost:27017"
     DB_NAME="lifeos_db"
     CORS_ORIGINS="*"
     EMERGENT_LLM_KEY="your_api_key_here"
     JWT_SECRET="your_secure_random_jwt_secret"
     ADMIN_EMAIL="demo@lifeos.app"
     ADMIN_PASSWORD="lifeos123"
     FRONTEND_URL="http://localhost:3000"
     ```

5. Start the FastAPI backend server:
   ```bash
   python server.py
   # or with uvicorn:
   uvicorn server:app --reload --port 8000
   ```

The backend API will be available at `http://localhost:8000`. API documentation (Swagger UI) will be accessible at `http://localhost:8000/docs`.

---

### Frontend Setup

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   yarn install
   # or
   npm install
   ```

3. Configure environment variables:
   - Copy `.env.example` to `.env`:
     ```bash
     cp .env.example .env
     ```
   - Verify `REACT_APP_BACKEND_URL`:
     ```env
     REACT_APP_BACKEND_URL=http://localhost:8000
     ```

4. Start the development server:
   ```bash
   yarn start
   # or
   npm start
   ```

The application will open in your browser at `http://localhost:3000`.
